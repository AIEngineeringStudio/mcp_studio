# Pattern Learning Checkpoint

Use at an interactive lesson boundary or when the learner asks to pause.
Keep it short, omit unused fields, and fill it with observed evidence. State
that it can be pasted into a future chat; do not claim it was saved as memory.

```text
DESIGN PATTERN CHECKPOINT
Language and example domain:
Current pattern and lesson step:
Status: introduced | practicing | complete
Demonstrated understanding:
Implementation and test evidence:
Key design insight:
Unresolved confusion or untested assumption:
Next exercise or lesson:
Resume: Continue at the recorded step; revisit earlier material only as needed.
```

Use `complete` only when the assessment reference's completion evidence exists.
Copied examples, a delivered guide, or an unattempted exercise do not establish
independent understanding. If a supplied checkpoint lacks detail, identify the
uncertainty and resume with one relevant check rather than the entire course.
